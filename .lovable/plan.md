# Separar Ajustes de Perfil

## Cambios
- Crear una nueva pantalla «Ajustes» accesible desde el menú principal.
- Mover allí Meteorología, Intervals.icu, Strava, Telegram, Notificaciones y Readiness diario.
- Añadir una tarjeta «Idioma» con selector para castellano, catalán, francés, inglés y alemán.
- Mantener en Perfil únicamente los datos personales, deportivos, nutricionales y la eliminación de perfil.
- Conservar el guardado actual de preferencias y conexiones.

## Verificación
- Comprobar Perfil y Ajustes en móvil y escritorio.
- Confirmar que el idioma se guarda y que las conexiones y preferencias siguen funcionando.
